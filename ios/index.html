📱 DEVICE HARDWARE GUIDANCE
1. Developer Options (Smallest Width / DPI):
Navigate to Settings ➔ Developer Options ➔ Smallest Width. Set to 480–540 dp for optimal drag response. Avoid setting over 800 dp on Xiaomi or Infinix to prevent UI glitches.
2. Touch & Hold Delay:
Navigate to Settings ➔ Accessibility ➔ Touch ➔ Touch & Hold Delay. Set to Short (0.5 seconds) for faster drag shot reaction time.
3. Pointer Speed:
Navigate to Settings ➔ System ➔ Languages & Input ➔ Pointer Speed. Set the slider to center or notch 7/10 to avoid jitter.
4. Force Maximum Refresh Rate:
If your display supports 90Hz/120Hz/144Hz, ensure High Refresh Rate is forced in display settings. Higher Hz increases touch polling rate (e.g. 240Hz/360Hz touch).
1. Touch Accommodations & Tap Duration:
Open Settings ➔ Accessibility ➔ Touch ➔ Touch Accommodations. Enable Tap Duration and set to 0.10s. Keep Ignore Repeat OFF to enable instant drag registration.
2. Haptic Touch Responsiveness:
Navigate to Settings ➔ Accessibility ➔ Touch ➔ Haptic Touch. Set Touch Duration to Fast for snappier fire button recognition.
3. Pointer Control Tracking Speed:
Navigate to Settings ➔ Accessibility ➔ Pointer Control. Slide Tracking Speed to 70%–80%. This smooths micro-adjustments during scoped tracking.
4. 120Hz ProMotion vs 60Hz Tuning:
iPhone 13 Pro through 16 Pro Max have 120Hz ProMotion with 240Hz touch sampling. Use slightly lower General sensitivity (165–175) to prevent overshooting enemy heads. Standard 60Hz iPhones (iPhone 11–15 base) perform best at 185–195 General.
